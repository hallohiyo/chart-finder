# 살짝 빗나간 추천 (chart-finder)

유튜브 시청 기록으로 관심사를 파악하고, **평소엔 접하지 않지만 관심사와 이어지는 "적당히 빗나간" 주제**를 하루 하나씩 추천하는 크롬 확장 프로그램입니다.

> 음악을 좋아하시니까 이것도 재밌을 거예요. 악보의 개념을 몸의 움직임으로 확장한 거예요.
> — 오늘의 주제: **라바노테이션 (춤의 악보)**

## 설치 (개발 모드)

1. `chrome://extensions` → 우측 상단 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension/` 폴더 선택
3. 설치하면 설정 페이지가 열립니다. 선택 사항:
   - **YouTube Data API 키**: 넣으면 설명·태그·카테고리까지 분석해 더 정확해집니다 ([Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com)에서 YouTube Data API v3 사용 설정 → API 키 생성). 없으면 페이지 제목만으로 동작합니다.
   - **지난 시청 기록 가져오기**: 최근 90일 방문 기록에서 `youtube.com/watch` 주소만 골라 가져와 바로 시작할 수 있습니다.
4. 유튜브 영상을 5개 이상 보면 툴바 아이콘 팝업에 오늘의 추천이 나타납니다.

```bash
npm test          # 단위 테스트 (Node 20+, 의존성 없음)
npm run package   # 웹스토어 업로드용 slightly-off.zip 생성
```

## 동작 방식

```
youtube.com/watch 15초 이상 시청
  → content.js 가 영상 ID + 제목을 백그라운드로 전달
  → (API 키가 있으면) YouTube Data API 로 제목·설명·태그·카테고리 보강
  → 개념 임베딩 → 관심 지도(군집) → 중간 거리 주제 선택 → 팝업
  → 재밌어요 / 별로예요 → 추천 거리와 분야 선호 조정
```

### 1. 개념 임베딩 (로컬)

외부 모델 없이 브라우저 안에서 계산하기 위해 [ESA(Explicit Semantic Analysis)](https://en.wikipedia.org/wiki/Explicit_semantic_analysis) 방식을 씁니다.

- `src/data/domains.js`의 27개 **도메인**(음악, 게임, 물리, 역사…)이 벡터의 축입니다. 각 도메인에는 한/영 키워드가 있고, 영상의 제목·태그·설명·카테고리를 매칭해 도메인 벡터를 만듭니다.
- **도메인 연관 그래프**(음악–물리 0.4, 요리–화학 0.5 …)로 한 번 스무딩해서, 키워드가 겹치지 않아도 이웃 분야끼리는 가깝게 만듭니다.
- 추천 주제(`src/data/topics.js`, 47개)도 같은 공간에 놓입니다. 대부분 2~3개 분야에 걸친 "다리" 주제입니다 (예: 마이야르 반응 = 요리 + 화학).

### 2. 관심 지도

시청한 영상 벡터를 **최근성(반감기 30일) × 반복 시청(로그)** 가중치로 k-means 군집화합니다 (최대 4개). 각 군집의 중심, 비중, 대표 영상이 "관심 지도"이고, 설정 페이지에서 직접 볼 수 있습니다.

### 3. "살짝 빗나간" 선택

각 주제에 대해 **가장 가까운 관심 군집까지의 코사인 거리**를 구하고, 목표 거리(기본 0.45) 주변의 가우시안으로 점수를 매깁니다. 너무 가까운 주제(이미 아는 분야)와 너무 먼 주제(연결고리가 없는 분야)는 자연스럽게 밀려납니다. 가장 가까웠던 군집이 연결고리가 되어 "○○을 좋아하시니까…" 문장과 대표 영상이 함께 표시됩니다.

- 최근 60일 안에 추천했거나 "별로예요"를 받은 주제는 제외
- 날짜 기반 ±5% 흔들림으로 비슷한 후보 중 매일 다른 선택

### 4. 반응에 따른 조절

| 반응 | 목표 거리 | 분야 선호 |
|---|---|---|
| 😄 재밌어요 | 그 추천 쪽으로 25% 이동 + 0.03 (조금 더 멀리 탐험) | 해당 주제 분야 ↑ |
| 🤔 별로예요 | −0.05 (관심사 쪽으로) | 해당 주제 분야 ↓ |

목표 거리는 0.2~0.85 범위로 제한됩니다. 반응은 추천당 한 번만 반영됩니다.

## 개인정보 & 웹스토어 정책

자세한 내용은 [PRIVACY.md](PRIVACY.md)를 보세요. 요약하면:

- **권한 최소화**: 기본 권한은 `storage`, `alarms`, `youtube.com` 콘텐츠 스크립트, `googleapis.com/youtube/v3` 호출뿐입니다. 전체 방문 기록(`history`)은 **선택 권한**으로, "가져오기" 버튼을 누를 때만 요청하고 끝나면 즉시 반납합니다.
- **로컬 처리**: 모든 데이터는 `chrome.storage.local`에만 저장되고 분석도 브라우저 안에서 합니다. 개발자 서버가 없습니다.
- **최소 수집**: 15초 이상 머문 영상의 ID·제목(+API 메타데이터)만 저장, 180일/1,000개가 지나면 자동 삭제.
- 시크릿 모드 미지원(`"incognito": "not_allowed"`), 수집 일시정지, 데이터 전체 삭제 제공.

## 구조

```
extension/
  manifest.json
  src/
    background.js        서비스 워커: 메시지 라우팅, 알람, 기록 가져오기
    content.js           youtube.com 시청 감지 (15초 체류 후 ID+제목 전송)
    lib/
      embedding.js       개념 임베딩 + 거리
      interest-map.js    가중 k-means 관심 지도
      recommender.js     중간 거리 선택, 연결 이유, 반응 반영
      service.js         하루 추천 한도/상태 관리 (chrome 비의존, 테스트 가능)
      store.js           chrome.storage.local 래퍼 (쓰기 직렬화, 보관 기간)
      youtube.js         URL 파싱, Data API 조회
      korean.js          조사(을/를) 처리
    data/
      domains.js         도메인 사전, 연관 그래프, 카테고리 매핑
      topics.js          추천 주제 카탈로그
  popup/                 오늘의 추천 + 반응 버튼
  options/               설정, 관심 지도 보기, 기록 가져오기, 데이터 삭제
tests/                   node:test 단위 테스트
```
